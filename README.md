## 🚀 Builds — problem → build → learned

**📚 NPTEL Exam Practice Hub**

*Problem:* NPTEL Geography & Environment had no mobile-first practice, and NPTEL publishes no public answer key.
*Build:* 130 portal-verified MCQs (Weeks 0–12), submit-all week tests, timed mocks, study questions and smart revision — Google/email sign-in, Firebase-synced progress.
*Learned:* Verification beats claims — every answer was matched against the portal before shipping.

*Problem:* Identifying fabric from a photo, and giving the right care advice, was hard.
*Build:* CNN pipeline for photo-based fabric classification with care recommendations.
*Learned:* Lab accuracy and real-world accuracy are different — real photos are the real test.
