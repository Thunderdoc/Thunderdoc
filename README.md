## 🚀 Builds — problem → build → learned

**📚 NPTEL Exam Practice Hub**

*Problem:* NPTEL Geography & Environment had no mobile-first practice, and NPTEL publishes no public API or question bank.
*Build:* 130 portal-verified MCQs (Weeks 0–12), submit-all week tests, timed mocks, study questions and a final exam.
*Learned:* Verification beats claims — every answer was matched against the portal before shipping.
